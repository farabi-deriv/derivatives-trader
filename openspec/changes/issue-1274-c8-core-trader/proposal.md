## Why

`@deriv/core` and `@deriv/trader` are the last two reservoirs left by the C1–C2 extraction sweep, the C7 `@deriv/shared` sweep (`dead-code-removal`, DCR-001…DCR-019) and the C8-small sweep (DCR-020…DCR-033). Between them they carry roughly **11,500 lines of unreachable source, ~6,000 lines of dead SCSS, ~1.6 MB of orphaned assets and 21 undeclared-dead dependencies**.

The two halves fail differently. `packages/core` is heavily `.jsx`, excluded from `tsconfig.json`, so a whole render chain can go unreachable without a single warning: `App/Containers/Layout/header/show-notifications.tsx` has **zero consumers**, and with it `ToggleNotifications`, `NotificationsDialog`, `notification-list-wrapper`, `notifications-list`, `notifications-clear-all-footer` and 249 lines of `notifications-dialog.scss` are all shipped and never rendered. `packages/trader` fails through the AppV2 redesign: `AppV2/Containers/Trade/index.ts` exports only `./trade`, which renders `trade-desktop`/`trade-mobile` — neither imports `trade-types.tsx`, so the entire TradeTypes cluster (`TradeTypesSelector`, `DraggableList`, `useIsTradeTypeSelectionRestricted`, 1,325 LOC of components alone) plus its `react-beautiful-dnd` dependency is compiled, bundled and unreachable. The whole `Assets/Trading/Categories/` tree (2,538 LOC, 20 Description files) has **zero importers** outside itself except `icon-trade-categories.tsx`, which is live. `packages/trader/src/public` is 107 files and 908 KB behind a **commented-out** `CopyPlugin` — nothing even ships.

This is GitHub issue [#1274](https://github.com/deriv-com/derivatives-trader/issues/1274). It is cut from `akmal/issue-1273-c8-small` (itself cut from `akmal/issue-1272-shared-sweep`) and targets that branch. The stacking is deliberate: #1273 and #1274 both regenerate `docs/baselines/knip-baseline.json` and `docs/baselines/alias-usage.json`, and serialising them avoids a guaranteed JSON conflict.

**The issue exceeds one run.** The plan is authored as ordered, independently-green phases; each phase leaves the tree building and testing green on its own, ticks land the instant a phase does, and the run resumes with `dstp continue "akmal/issue-1274-c8-core-trader"`.

## What Changes

Delete `App/Components/Routes/helpers.ts` in full with its spec and barrel line, drop the dead `LanguageLink`/`RouteWithSubRoutes` named exports, the `binary-routes.jsx` account-closed regex and `notification.jsx`'s `case 'news'`. Delete `_common/lib/`, the two 0-byte `client_base.js`/`currency_base.js`, and `utility.js`'s dead pair. De-export `socket-general.authorizeAccount`, delete the PWA `unregister` export, `Services/logout.js`'s test-only `requestLogout`, and `Constants/currency.js`. Delete `src/public/fonts/` (264 KB), `static_images/presets-onboarding/` (212 KB), `plus.svg` and the orphaned SVGs, and retire the `Fonts`/`Translations` alias from **both** places that still declare it. Prune ~2,400 lines of SCSS led by `account-common.scss` (1,083). Correct the manifest.
- **C8c — `packages/trader` (~7,500 LOC + ~1,957 test LOC + 908 KB + 6 deps).** Delete the TradeTypes cluster (`Containers/Trade/trade-types.tsx`, `trade-types-content.tsx`, `Components/TradeTypesSelector/`, `Components/DraggableList/`, `Hooks/useIsTradeTypeSelectionRestricted.ts`), freeing `react-beautiful-dnd`, `@types/react-beautiful-dnd`, the `pinned_trade_types` localStorage key and `Assets/SvgComponents/ic-grid.svg`. Delete the whole `Assets/Trading/Categories/` tree **except `icon-trade-categories.tsx`**, which `MarketSelection/market-info-screen.tsx:28` renders. Delete `SymbolNotFound/`, `SymbolsSearchField/`, `Modules/Contract/Components/AccumulatorsStats/`, the InfoBox tree, `ContentLoader/trade-params.tsx`, the dead hooks and re-exports. Delete `src/public/` and the `Fonts`/`Images`/`Translations` alias entries in `packages/trader/tsconfig.json`. Clean `build/helpers.js`, `generateSWConfig`/`htmlOutputConfig`, the `is_test_env` eslint-loader block, the duplicate `.eslintrc.ts` and the stale `index.d.ts` shim. Prune ~3,600 lines of SCSS. Correct the manifest.
- **SCSS lands last within each package.** It is the highest-risk category and has the strongest gate (sass-loader hard-fails the build), so it is the best thing to be holding when a run stops. The ordering is also load-bearing, not merely prudent: `contract-type-info.scss`'s classes are referenced today by the `Categories/Description/*` files, so it only becomes dead **after** the TSX phase.
- **Two new package-local guard specs** — `packages/core/src/__tests__/dead-code-sweep.spec.ts` and `packages/trader/src/__tests__/dead-code-sweep.spec.ts` — following the pattern already established in `shared`, `components`, `reports`, `api`, `stores` and `utils`. They pin the deletions and, more importantly, pin the KEEP set.
- **The KEEP set is preserved verbatim**: `socket_cache.getByMsgType` (duck-typed by `@deriv/deriv-api`, grep-invisible by design), `socket_base.sendKeepAlive` / `waitForAuth`, `categorizeSymbols`, `icon-trade-categories.tsx`, `Config/trade-parameter-presets.ts`, the four AppV2 `commission` copy sites, `purchase-button.tsx`'s `useRiskDisclosure` gating, `.reset-password*`, the "Deposit now" / "Try real" cross-app redirects and the `trading_disabled` account-status gating.
- **Eighteen measured corrections to the issue body** are resolved by report, never by substitution — see `design.md`. The largest: the `Fonts`/`Images`/`Translations` map is **not** in "3 copies" (trader has 1, in tsconfig; core has 2, in `build/constants.js` and `knip.json`); core's `BinaryLink` is **live**; `LiveChat` does not exist at HEAD; `RecentTradeInfo` **is** rendered; `packages/trader`'s type baseline is **0**, not non-zero.
- **Verification.** Record `npx tsc -p packages/{core,trader}/tsconfig.json --noEmit` counts before any edit and gate every later check at `≤`. Regenerate and commit `docs/baselines/knip-baseline.json` and `docs/baselines/alias-usage.json`.

## Impact

**Packages touched:** `@deriv/core` (primary), `@deriv/trader` (primary). Repo-root `knip.json` (its `packages/core` `paths` block is the second copy of the core alias map).

**Explicitly NOT touched:** `packages/shared`, `packages/components`, `packages/reports`, `packages/api`, `packages/stores`, `packages/utils` — they belong to the parent changes C7 (#1272) and C8-small (#1273), both in this branch's history and both with in-flight PRs. This constraint has one concrete cost: `packages/shared/src/__tests__/dead-code-sweep.spec.ts:54` reads `packages/core/src/App/Components/Routes/language-link.tsx` by path, so deleting that file would fail a `packages/shared` spec. `language-link.tsx` is therefore **kept** in this change and deferred.

**Public API:** none. Neither package exports a public surface: `@deriv/core` is the app shell (`private: true`) and `@deriv/trader` is consumed only through `core`'s lazy `import('@deriv/trader')`. The `Fonts` / `Translations` aliases (core) and `Fonts` / `Images` / `Translations` (trader) are removed from the build's resolvable roots; no source file imports through any of them.

**Dependencies:** `packages/core` −15 runtime, 2 moved to `devDependencies` (`null-loader`, `dotenv-webpack`); `packages/trader` −6 runtime (incl. `react-beautiful-dnd`), −1 devDependency (`@types/react-beautiful-dnd`), 1 moved to `devDependencies` (`null-loader`). `package-lock.json` changes, so the first CI `test` run is expected to time out on a cold npm cache.

**Docs:** `docs/baselines/knip-baseline.json` and `docs/baselines/alias-usage.json` regenerated and committed. Four deferral files under `docs/spec-to-pr/deferrals/`.

**Behaviour:** none intended. Every deletion is of a file, symbol, asset or dependency with zero reachable consumers. The one deliberate product change is the cookie banner's removal, decided late Aug 2026 and already hard-disabled at `app-contents.jsx`.

**CI:** this PR runs only **3 of 11** checks. `.github/workflows/test.yml` is filtered to `pull_request: branches: [master]` and this PR targets a feature branch, so Build Project, TypeScript & Linting, all three Jest groups and the SCA scan do not run. Local verification is the only real gate and its numbers go in the PR description.
